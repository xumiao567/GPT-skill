## 使用与验证

拖动查看动态反光，「翻面」阅读卡背，「自动摆动」连续观察镭射效果，「保存图片」保存当前角度。四个滑杆调节镭射和景深。键盘 F 翻面，R 复位。

源码版和单文件版均通过 Chromium 的模型/图层加载、拖动、翻面返回、镭射滑杆、自动复位、图片保存、390px 窄屏和模拟手机触控检查，没有控制台错误。实体手机未实测。云浏览器限制 file://，单文件通过本地 HTTP 测试；本地双击打开未在云环境中实测。

图画由用户参考图经图像生成适配，中文寄语和编号采用精确字体排版。Blender 工程图片已打包、带自定义中文背面；网页与 Blender 的灯光和色彩会有差别。

使用 [EverettFish/holo-card-studio](https://github.com/EverettFish/holo-card-studio) 制作，技能和 Three.js 许可证包含在工程内。
